UI Scale 1x - sharp, compact UI for Cossacks 3 at 4K

The game doubles the UI above 1535 px screen height. This keeps it at 1x, so
original textures and fonts are drawn pixel for pixel and more of the map is
visible. The UI is half the size of the standard 4K UI.
Also pads the tooltip textures to reduce edge lines.

Note: replaces data\scripts\lib\gui.script, so it may affect who you can join
in multiplayer, and may need updating after a game patch.
Do not combine with "HD Fonts 4K".

Install: copy the "UI Scale 1x" folder into "Cossacks 3\mods".
Uninstall: close the game and delete that folder.
