# Cossacks 3 mods

| Folder | What it does |
|---|---|
| `HD Fonts 4K` | Sharp UI text at 4K (2x UI scale) |
| `UI Scale 1x` | Keeps the UI at 1x at 4K |
| `Startup Fix` | Shortens config tool and game startup (not a game mod, see its README) |

Install a mod by copying its folder into `Cossacks 3\mods`. Use only one of the two UI mods at a time.

`source` holds the build scripts. `build.py` needs LinLibertine_R.otf, LinBiolinum_R.otf and
OpenSans-Regular.ttf in `source/fonts`, plus Pillow, NumPy and fontTools.

The UI mods contain modified Cossacks 3 files, which belong to their original owner.
