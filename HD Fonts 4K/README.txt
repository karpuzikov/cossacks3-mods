HD Fonts 4K - sharp UI text for Cossacks 3 at 4K (2x UI scale)

- 2x resolution font atlases (code pages 1250, 1251, 1252, 1254) with linear
  filtering. Glyph sizes, spacing and layout are unchanged.
- Repositions the tooltip textures with padding to prevent edge lines.

Use for the standard 2x UI. Do not combine with "UI Scale 1x".

Install: copy the "HD Fonts 4K" folder into "Cossacks 3\mods".
Uninstall: close the game and delete that folder.

Fonts: Linux Libertine and Linux Biolinum (SIL OFL / GPL, Libertine Open Fonts
Project) and Open Sans (Apache License 2.0). A few symbols are upscaled from
the game's originals. Tooltip textures are modified game files.
